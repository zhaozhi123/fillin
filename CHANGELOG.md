# Changelog

All notable changes to Fillin will be documented in this file.

The project follows [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added

- English-first open-source documentation and localized Chinese documentation.
- English and Chinese Chrome Web Store artwork generated from fictional websites.
- Manifest localization for English and Simplified Chinese.
- English and Simplified Chinese side-panel localization.
- Privacy policy, permission rationale, security policy, contribution guide, and CI checks.
- HTTPS enforcement for remote AI endpoints, with HTTP limited to local development services.

## [0.1.0] - 2026-07-27

### Added

- Initial Manifest V3 Chrome Side Panel extension.
- Context-aware field detection, AI generation, local fallback data, verification, and undo.
- Long-form and rich-text editor support.
- Local AI configuration backup and restore.
